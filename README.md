# WebIDE + Local LLM

Полноценная веб-среда разработки с доступом к файловой системе и интеграцией с локальной LLM.

## ✨ Возможности

- 📂 **Доступ к файловой системе** — открытие, редактирование и сохранение файлов на вашем ПК
- 🤖 **Локальная LLM** — интеграция с Ollama для помощи с кодом
- ✏️ **Редактор кода** — подсветка синтаксиса для 10+ языков (JS/TS, Python, Rust, C++, HTML, CSS, JSON, Markdown)
- 💬 **Чат с LLM** — задавайте вопросы о коде, получайте помощь в отладке
- 🖥️ **Встроенный терминал** — базовые команды
- 🎨 **Тёмная тема** — приятная для глаз тема в стиле VS Code
- 🖥️ **Кроссплатформенность** — работает на Linux и Windows

## 🚀 Установка и запуск

### 1. Установите Ollama (для локальной LLM)

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Windows:**
Скачайте с https://ollama.com/download

### 2. Запустите Ollama и загрузите модель

```bash
# Запустите сервер
ollama serve

# В другом терминале загрузите модель (выберите любую)
ollama pull llama3.2          # Универсальная модель
ollama pull qwen2.5-coder     # Специализирована для кода
ollama pull deepseek-coder-v2 # Ещё одна модель для кода
ollama pull codellama          # Code Llama от Meta
```

### 3. Откройте WebIDE

Откройте приложение в **Chrome** или **Edge** (для доступа к файловой системе через File System Access API).

> ⚠️ Firefox не поддерживает File System Access API. В Firefox можно использовать drag & drop.

## 📖 Использование

### Работа с файлами
1. Нажмите **"Открыть папку проекта"**
2. Выберите папку в диалоге
3. Кликайте по файлам для открытия в редакторе
4. **Ctrl+S** для сохранения файла

### Работа с LLM
1. Убедитесь, что Ollama запущена (`ollama serve`)
2. Откройте настройки (⚙️) и выберите модель
3. Включите контекст текущего файла для более точных ответов
4. Задавайте вопросы в чате

### Рекомендуемые модели для кода
| Модель | Размер | Описание |
|--------|--------|----------|
| qwen2.5-coder | 7B/14B | Отлично для кода |
| deepseek-coder-v2 | 16B | Сильная модель для кода |
| codellama | 7B/13B | Специализирована для кода |
| llama3.2 | 3B/8B | Хорошая универсальная |
| starcoder2 | 3B/7B | Для автодополнения |

## 🔧 Настройка

В настройках можно изменить:
- **Endpoint** — адрес Ollama сервера (по умолчанию `http://localhost:11434`)
- **Модель** — какую модель использовать
- **Temperature** — креативность ответов (0 = точно, 2 = креативно)
- **Max Tokens** — максимальная длина ответа

## 🛠️ Технологии

- React + TypeScript
- CodeMirror 6 (редактор кода)
- Tailwind CSS (стили)
- Ollama API (локальная LLM)
- File System Access API (доступ к файлам)

## 📝 Примечания

- Приложение работает полностью в браузере, данные не отправляются на внешние серверы
- Все запросы к LLM идут только на локальный Ollama сервер
- Файлы читаются/пишутся напрямую на вашем компьютере
